- 保存した動画とダウンロードの一覧で、クリックで選べるようになりました。Ctrl（Mac は ⌘）や Shift を押しながらのクリック、Ctrl+A で、まとめて選べます
- 右クリックで「…」と同じメニューが出ます。選んだものすべてに、まとめて使えます。ソースの行でも右クリックが使えます
- Delete（Mac は ⌘+Delete）でごみ箱へ移す、F2（Mac は Return）で名前を変更、Enter で開く・詳細を表示ができます
- ダウンロードの一覧から行を外せるようになりました。保存したものは「保存した動画」に残ります
- ダウンロードの一覧からも、名前の変更・ごみ箱へ移す・プログラムから開くができます。保存した動画と同じファイルとして扱います
