- yt-dlp が扱うサイトから動画と音声を保存できます。キューで順に保存し、画質はプリセットから選べます
- サイトごと・アカウントごとに、アプリの中でログインできます。Firefox のログインを取り込むこともできます
- 「集める」で、どのページからでも動画のリンクを集めて保存できます。集め方は規則として残せます
- 「ソース」に登録したチャンネルや一覧の新着を確かめられます。アプリを開いている間、自動で確かめることもできます
- ページにある画像を選んで保存できます
- 保存した動画の一覧から、開く・名前を変更・ごみ箱へ移す・一覧から外すができます
- アプリの中のブラウザで広告をブロックできます（Windows）
- ダウンロードの完了や失敗、新着を通知でお知らせします（Windows）
- 新しい版をアプリの中で確かめて、そのまま更新できます
