- 「手順を覚える」を足しました。アプリの中のブラウザで、カードを押す・ポップアップの再生を押す、といった操作を一度してみせると、その手順を覚えます
- 覚えた手順は「くり返して集める」で、ほかのカードにも同じようにくり返せます。範囲は「この1つ」「この列の残り」「同じ種類すべて」から選べます。見えない窓で1件ずつ行い、集まった動画はキューに追加できます
- 覚えた手順はサイトごとに保存でき、次に同じサイトを開いたときに「保存した手順」から「使う」で呼び出せます。名前の変更と削除は、設定 > サイトからできます
- ページの作りが変わって手順が合わなくなったときは、途中で止めて「記録しなおす」を出します
