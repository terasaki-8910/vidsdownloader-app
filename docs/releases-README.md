# vidsdownloader

動画と音声を保存するデスクトップアプリ（Windows / macOS）の配布場所です。インストーラーと更新のファイルだけを置いています。

## 入れ方

[Releases](https://github.com/terasaki-8910/vidsdownloader-releases/releases/latest) から、使っている OS のファイルをダウンロードします。

### Windows

1. `vidsdownloader_<版>_x64-setup.exe` を開きます。
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押してから「実行」を押します（発行元の署名を付けていないためです。最初の1回だけで、更新では出ません）。
3. ユーザーごとに入ります。管理者の許可は要りません。

### macOS

1. `vidsdownloader_<版>_universal.dmg` を開き、vidsdownloader を「アプリケーション」に入れます。
2. 最初に開いたとき「開けません」と出たら、システム設定 > プライバシーとセキュリティ を開き、下のほうの「このまま開く」を押します（発行元の署名を付けていないためです。最初の1回だけです）。

## 最初の起動

yt-dlp、ffmpeg、Deno をダウンロードし、SHA-256 で確かめてから使います。これらはインストーラーに入っていません。

## 更新

起動したときに新しい版を確かめ、見つかるとお知らせします。「今すぐ更新」「あとで」「この版はスキップ」から選べます。ダウンロード中は更新しません。設定 > アップデート からも確かめられます。

## 使うときの注意

DRM のかかったものや、有料・ログインの壁で守られたものを越える機能はありません。それぞれのサイトの利用規約に従って使ってください。
